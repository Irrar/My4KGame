# 协作指南（GitHub）

> 这份文档是给"拿到这个仓库的人"看的：怎么获取、怎么打开、怎么改、怎么提交。
> 仓库：https://github.com/Irrar/My4KGame

---

## 0. 三个前提

| 项 | 说明 |
| --- | --- |
| 仓库是私有的 | 必须先被邀请为**协作者**，否则克隆会 404 |
| Unity 版本 | **2022.3.62f3c1**（同系列 2022.3.x 也能开，最好统一） |
| 额外模块 | 不需要 Android / WebGL；要打包 exe 才需要 Windows Build Support |
| 仓库体积 | 约 12MB（`Library/` 已被 `.gitignore` 排除），克隆很快 |

---

## 1. 仓库所有者要做的一次性操作（加人）

1. 打开仓库 → **Settings** → 左侧 **Collaborators**
2. 点 **Add people**，输入对方的 GitHub 用户名或邮箱，选人 → **Add**
3. 对方会收到邮件/通知，**接受邀请**后才生效
4. 之后对方就能 `git clone` 和 `git push`

> 如果只是想让人"看"，不想让人改：Settings → 最下方 **Danger Zone** → **Change repository visibility** → Public。
> 公开后任何人可以克隆，但**不能直接 push**，需要 Fork 后提 PR。

## 2. 拿到并运行

### A. 克隆（参与开发就用这个，能拿到完整历史）

```bash
git clone https://github.com/Irrar/My4KGame.git
cd My4KGame
```

- Unity Hub → **Add** → 选择刚克隆出来的 `My4KGame` 文件夹 → 用 2022.3.62f3c1 打开
- 首次打开会导入 2~5 分钟
- 打开后会自动进入 `Assets/Scenes/My4KGame.unity`；若停在空白场景（Untitled），双击该场景，或点菜单 **My4KGame → 0. 打开游戏场景**
- 按顶部 **▶** → 选难度 → `D` `F` `J` `K` 开始玩

### B. 只想试玩（不参与开发）

- 网页 → 绿色 **Code** → **Download ZIP** → 解压 → 用 Unity 打开；或
- 直接找仓库所有者要打包好的 `Build` 文件夹（双击 `My4KGame.exe` 就能玩，不用装 Unity）

## 3. 改完怎么提交（推荐：分支 + Pull Request）

```bash
# 1) 先同步最新代码
git pull --rebase origin main

# 2) 开一个分支（名字随便，能看懂就行）
git checkout -b feature/你的改动

# 3) 改代码 / 改谱面 / 改 UI ...

# 4) 提交并推送
git add -A
git commit -m "改了什么，一句话说清"
git push -u origin feature/你的改动
```

然后到 GitHub 仓库页面，会看到 **Compare & pull request** 按钮 → 填说明 → **Create pull request** →
所有者（Irrar）review 后点 **Merge pull request**。

> 两个人的小改动也可以直接推 `main`，但**不要同时改同一个场景**，否则冲突很难受。

## 4. 同步别人的改动

```bash
git pull --rebase origin main
```

VS Code 里 **Source Control → Sync Changes** 等价于 `pull --rebase` + `push`，建议就用它。

## 5. Unity 协作的 4 条铁律

1. **不要提交缓存目录**：`Library/`、`Temp/`、`Logs/`、`obj/`、`UserSettings/` 都已在 `.gitignore` 里；
   每个人的 `Library` 由 Unity 自己生成，提交上去只会让仓库暴涨到几百 MB。
2. **`.meta` 文件必须一起提交**：Unity 靠它记录 GUID，少一个就会"引用丢失/粉红材质"。
3. **场景与预制体是 YAML 文本**（本工程已设 Force Text），能 diff 但**很难手合并** →
   分工建议：一个人改场景/预制体，另一个人改 C# 脚本。
4. **拉完代码先自检**：菜单 **My4KGame → 1. 一键生成全部**（重建贴图/预制体/场景），
   再 **My4KGame → 5. 自检**；全绿再动手，能排掉 90% 的"我这跑不起来"。

## 6. 常见问题

| 现象 | 原因与解决 |
| --- | --- |
| `clone` 报 404 | 仓库是私有的，且你还没被加为协作者 / 没接受邀请 |
| Unity 提示版本不一致 | 装 2022.3.62f3c1；或用同系列 2022.3.x 打开（会让你升级，团队最好统一） |
| 打开是一片蓝天灰地（Untitled） | 双击 `Assets/Scenes/My4KGame.unity`，或菜单 `My4KGame → 0` |
| `push` 被拒：non-fast-forward | `git pull --rebase origin main` 再推，**不要用 `--force`** |
| `push` 报 `Connection was reset` 或超时 | 国内直连 GitHub 的 HTTPS 不稳定，改用 SSH（见下） |
| 场景里脚本显示 Missing | 关掉 Unity 重开让它重新编译；仍不行就菜单 1 重新生成 |

### 改用 SSH（HTTPS 不稳时最有效）

```powershell
ssh-keygen -t ed25519 -C "你的邮箱"
# 把 ~/.ssh/id_ed25519.pub 的内容贴到 https://github.com/settings/ssh/new
ssh -T git@github.com          # 看到 "Hi 用户名!" 就成功
git remote set-url origin git@github.com:Irrar/My4KGame.git
```

若 22 端口被封，在 `~/.ssh/config` 里加：

```
Host github.com
    HostName ssh.github.com
    Port 443
    User git
```
