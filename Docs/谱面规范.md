# 谱面规范 & 工具

> 这份文档写给"继续写谱 / 改谱"的人。踩过的坑都写在前面，照着做就不会再出
> "Hold 还没松手，同轨又来一个 tap" 这种让玩家打不了的谱。

---

## 一、三条硬规则（违反必出 bug）

| # | 规则 | 违反的后果 |
| --- | --- | --- |
| 1 | **同一轨道，Hold 持续期间不允许有任何其它音符** | 那段时间按键会被吞（见下方原理），谱面上的音符打不出来 → 必 MISS |
| 2 | **Hold 结束后，同轨至少留 140ms 空白** | 玩家来不及松手再按，实际打不出来（"反盾"太紧） |
| 3 | **同一时刻、同一轨道不允许有两个音符** | 叠在一起，只能判到一个 |

### 为什么规则 1 是致命的

`NoteSpawner.ResolvePress()` 第一件事就是：

```csharp
// 该轨道已有长按按住时，不再响应新的按压（简单模型）
if (_held[lane] != null) return Judgement.None;
```

也就是说 **Hold 按住期间，这条轨道的任何新按键都直接返回"空打"**。
如果谱面在 Hold 期间塞了一个 tap，玩家无论怎么按都打不中 —— 这不是难度，是 bug。

物理上也说得通：一根手指按着长条，不可能同时再点一下同一根手指所在的轨道。

## 二、工具：`tools/chart_tools.py`

```bash
# 只体检（不改文件）
python tools/chart_tools.py

# 修 Hold 冲突（所有谱面），只预览不写回
python tools/chart_tools.py --repair

# 修冲突 + 只给 Expert 重排键型，并且真的写回
python tools/chart_tools.py --repair --patterns expert --apply
```

参数说明：

| 参数 | 作用 |
| --- | --- |
| `--repair` | 把落在 Hold 区间内 / 贴太近的音符**挪到其它空轨道**；实在没位置才删 |
| `--patterns expert` \| `all` \| `none` | 键型重排范围（只动**连续单点**段落） |
| `--apply` | 真的写文件；不加就是预览 |
| `--root <工程目录>` | 指定工程根（默认脚本上一级） |

**它绝不动时间轴**：所有 `time` / `duration` 原样保留，只改 `lane`。
所以作者的采音不会被破坏，改的只是"用哪根手指打"。

体检输出示例：

```
chart                                     notes  holds  conflicts    bpm    key
InYourBlueEyes_Expert.json                  423     66          0    145   time
WorldsEndBLACKBOX_Expert.json               442    112          0    205   time
```

## 三、键型：交互 / 梯子 / 楼梯

参考《下落式音游齐民要术·排列》：<https://electrowind.github.io/VSRG-4K-wiki/pattern/pailie/>

| 键型 | 英文 | 4K 写法 | 手感 |
| --- | --- | --- | --- |
| 交互 | trill | `0 1 0 1` / `2 3 2 3` / `0 3 0 3` | 两指交替，高速下最稳 |
| 梯子 | rail / ladder | `0 1 2 3` / `3 2 1 0` | 一只手顺着轨道滑过去 |
| 楼梯 | staircase | `0 1 2 3 2 1` / `3 2 1 0 1 2` | 到顶/到底后折返，读谱有明确方向感 |

工具的做法：

- 把"连续单点"切成段；**段内不能有双押、不能夹 Hold**（Hold 会打断手感，键型不该跨过去）；
- 每段随机固定一个**交互对**（`0-1` / `2-3` / `0-3` / `1-2`），段内交替；
- 段长 ≥4 时插入一次**梯子**，≥6 时插入一次**楼梯**，方向每段随机；
- 目标轨道如果正被 Hold 占用，就退化成"挑一条空轨道"，**不硬塞**；
- 双押保持原样（避免把"对拍 / 对切"改成乱序）。

**采音原则**：工具只改轨道，不改时间。想加/删音符、改节奏，请人工按音乐来，
改完再跑一次 `--repair` 体检。
